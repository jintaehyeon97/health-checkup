## 1. 중복

```sql
SELECT base_year, member_id, COUNT(*) AS dup_cnt
FROM dbo.fact_checkup
GROUP BY base_year, member_id
```

## 처리 방침과 남은 일

- 범위 밖 값(dbp 3, fasting_glucose 7, waist_cm 12)은 **삭제·수정하지 않았습니다.** 측정 오류인지 실제 값인지 원본 데이터 설명서로 확인되지 않았기 때문입니다.
- waist_cm 999.0 은 결측을 뜻하는 코드일 가능성이 있으나 설명서로 확인하지 않았습니다. 분석에서 허리둘레를 쓸 때는 `waist_cm BETWEEN 40 AND 200` 같은 조건으로 거르는 것을 권장합니다.
- 적재 시 정수 컬럼의 소수값 6건(triglyceride 2, hdl 4)은 반올림해 적재했습니다 (Day 1 기록).
