- 대상: `healthdb.dbo.fact_checkup` 1,000,000행 (2023년), 인덱스 2개(ix_checkup_sido_bp, ix_checkup_year_age_sex) 생성 이후 상태

- 시간: `SET STATISTICS TIME` 의 실행(exec) / 컴파일(compile) 시간, client = Python 에서 실행~결과 수신까지
- 표는 쿼리별 상위 10행입니다 (소수 둘째 자리 반올림 표시). Q2, Q6a, Q6b 는 요약에 쓰기 위해 전체 행도 함께 적었습니다.
- ⚠️ 혈압·혈당 기준은 분석 예시용 단순 기준이며 의학적 진단이 아닙니다.
- ⚠️ 시도 비교(Q2, Q3, Q6b)는 **연령 보정을 하지 않은 값**입니다. 시도별 연령 구성 차이가 결과에 섞여 있을 수 있습니다.
- ⚠️ 흡연 상태 코드(1/2/3)의 의미는 스키마 주석(1 비흡연, 2 과거, 3 현재) 기준이며 **공식 코드표로 확인하지 않았습니다.**
